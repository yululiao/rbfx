# rbfx UI 编辑器使用指南

rbfx 编辑器内置的可视化 UI 编辑器（UI tab）用于创作 [RmlUi](https://mikke89.github.io/RmlUiDoc/) 界面文档（`.rml`）与配合样式表（`.rcss`）使用。它面向"流式/CSS 布局为主、绝对定位按需取用"的工作流，产出**与手写完全一致的标准 RML/RCSS**，不含任何私有格式或属性。

> 设计原则：**源文本是唯一真相源**。画布只是文本的实时投影；保存时只对真正改动的片段做最小差异补丁，绝不整文件重写。你随时可以在编辑器与手写之间自由切换，两者互不破坏。

---

## 1. 打开与新建文档

- **打开**：在 Resource Browser 中双击任意 `.rml` 文件。
- **新建**：聚焦任一 UI tab，点击工具栏 **New**（文件图标），在弹出的保存对话框中选择项目 `Data` 目录下的位置（新文档必须落盘才能成为资源）。
- 每个打开的 `.rml` 占据一个独立的编辑器 tab（"UI"、"UI (2)"……，VS Code 风格）。第一个 UI tab 是常驻入口：没有文档时显示空态提示，文档关闭后仍保留；后续实例随文档一起关闭。
- 已打开的文档再次双击时，编辑器会聚焦到已有的实例而不是重复打开。

## 2. 界面总览

| 区域 | 说明 |
|---|---|
| **工具栏**（顶部条） | New / Save / Reload（从磁盘重载，丢弃未保存编辑）、(unsaved) 标记、Play/Stop 预览、当前编辑文件名 |
| **画布工具条**（画布上方一行） | Wrap、Move Up/Down（流内顺序）、Fit、100%、缩放百分比、Canvas 尺寸选择 |
| **画布** | 文档的实时渲染预览，可直接点选、拖拽、编辑 |
| **Hierarchy** | 文档节点树（可拖拽重父化、右键菜单） |
| **Inspector** | 选中节点的属性面板（分区见第 6 节） |

## 3. 选择与画布交互

- **单击**选中元素；单击空白处清除选择。
- **Ctrl+单击**加选/减选（多选）；**按住左键拖出框**框选（小幅拖动退化为点击）。
- **双击**纯文本元素（如按钮、文字）进入**就地文字编辑**：Enter 提交，Esc 还原。
- **双击**嵌套模板节点可直接打开其源文件。
- **右键**元素弹出上下文菜单：Copy / Delete（多选时显示数量）、Wrap in Row/Column/Box、Move Up/Down。
- **中键拖动**平移视图；**滚轮**以指针为锚点缩放；`F` 键或 Fit 按钮适配窗口。
- **画布接受拖放**：从 Resource Browser 拖图片文件到画布可直接生成 `<img>` 元素（按纹理尺寸初始化）；从 Hierarchy 拖节点行到画布可移动该节点。

### 流式拖拽（换位 / 重父化）

按住**文档流内**的元素（非绝对定位）拖动：超过约 4px 阈值进入拖拽，绿色指示线/高亮实时显示落点（插入到某元素之前/之后，或进入某容器内部）；松手提交为一次可撤销的操作。未超过阈值的松手就是普通点击选中。拖拽中按 Esc 或右键取消。

### 绝对定位元素与 gizmo

设为 `position: absolute` 的元素（见第 5 节 Position）在画布上拥有完整 gizmo：

- **中心手柄**：移动。移动时自动**吸附对齐**——拖拽盒的左/中/右、上/中/下三条线会吸附到偏移父及兄弟元素的对应边与中心（屏幕 6px 阈值内），并以玫红色参考线提示当前对齐。松手提交的位置即吸附后位置。
- **8 个边角手柄**：调整大小（写回 width/height）。
- **顶边上方手柄**：旋转。
- **右下角外侧手柄**：等比缩放；右边缘外侧手柄为水平单轴缩放。
- 多选时一起拖动，所有元素跟随同一位移（含吸附），整体提交为一步 undo。
- 拖拽中 Esc 取消，元素回到拖拽前位置。

> 文档流内（In flow）的元素**没有** gizmo——这是设计行为：流内元素的位置由容器的布局属性决定，请通过容器的 flex 属性调整。

## 4. 添加控件

右键 Hierarchy 中的目标容器（或画布元素），选择 **Add Widget**：

- 顶部**过滤框**可按名称/分组快速检索。
- 分组清单（数据驱动，随版本演进）：

| 分组 | 条目 |
|---|---|
| Structure | `div`、`form` |
| Content | `img`（src 可空）、Text（`<p>`，直接进入文档流） |
| Controls | `button`、`input`（text / checkbox / radio / range / submit）、`select`（带两个 `<option>`）、`textarea`、`progress`、`label` |

- **Arbitrary tag**：清单底部可输入任意标签名创建元素——palette 是高频快捷方式清单，不是能力边界；任何 RmlUi 合法标签都可创建、渲染、编辑、保存。
- 惯用分工：**文字用 `p`，布局用 `div`，配控件的文字用 `label`**。

控件在未链接样式表的文档里可能显示为透明或占位框（编辑器会给原生控件画一个占位轮廓）；给文档 head 链接一份 rcss（见第 7 节）即可获得真实外观。

## 5. 布局编辑（Inspector → Layout 区）

选中任意元素后，Inspector 的 **Layout** 分区提供：

- **Position**：三态
  - **In flow**：由容器布局（默认）。
  - **Anchor**（`position: relative`）：仍在文档流中，同时成为绝对定位后代的参照物。
  - **Free**（`position: absolute`）：脱离文档流，可在画布上用 gizmo 拖动，相对最近的 Anchor/Free 祖先定位。
  - 切回 In flow 时只拔掉定位声明与 top/right/bottom/left，**保留已写尺寸**。
- **Z-order**（`z-index`）：叠放次序，留空即 auto（删除声明）。注意 CSS 规则：仅对已定位元素生效——需要 HUD 叠放/弹窗置顶时，先把元素设为 Anchor 或 Free。
- **Anchor 九宫格**（仅 absolute 元素）：选择盒子钉到哪条边/是否随容器拉伸；gizmo 拖动只写 top/left，重新钉边请回到这里点选。
- **Top / Right / Bottom / Left**：偏移值。
- **布局模式**：**Row / Column**（写 `display:flex` + `flex-direction`）或 plain box（留空）。
- **Gap**：子项间距（同时写 `row-gap` 与 `column-gap`）。
- **Align (main axis)**（`justify-content`）与 **Align (cross axis)**（`align-items`）。
- **Wrap**（`flex-wrap`）与 **Align lines**（`align-content`，仅 wrap 时可用）。
- **Align (self)**（`align-self`）：元素作为 flex 子项时的自身对齐。
- **Width / Height**：尺寸（`auto` 留空即删声明）。

定高容器做纵向滚动列表时，记得给子项设 `flex-shrink: 0`（走 Inline Style raw），否则子项会被压缩。

## 6. Inspector 分区参考

| 分区 | 内容 |
|---|---|
| **Content** | 编辑元素的文字内容（对纯文本元素生效，实时预览） |
| **Attributes** | 元素属性（id、class、type、src 等），资源类属性带浏览器按钮 |
| **Appearance** | background-color / opacity / color / font-size / text-align（继承属性带 `*` 标记）；**Background image** 编辑单图 decorator（`image(...)`，支持路径或精灵名，带资源选择按钮）。混合 decorator（叠加渐变等）显示为只读并提示走 raw，避免破坏你手写的内容 |
| **Layout** | 见第 5 节 |
| **Inline Style (raw)** | 原始 `style` 声明文本——结构化行覆盖不到的属性在这里手写，与手写代码完全同权 |
| **Computed** | 只读的最终计算值（调试用） |
| **Matched styles** | 每个生效属性的**来源追溯**：inline / rcss 规则（显示选择器与文件路径，点击可跳转到文本编辑器对应行）/ 继承 / 默认。排查"这个颜色到底哪来的"用它 |

## 7. 样式表与模板链接（head 节点）

文档 `<head>` 里的每条 `<link>` 在 Hierarchy 中是**一等节点**（🔗 图标）：

- **text/rcss 链接**：选中后可在 Inspector 编辑 href、删除；顶部添加行可新增（输入路径 + Stylesheet/Template 按钮）。
- **text/template 链接**：被 body 实例化的模板以 `#nested-doc` 节点显示（可双击打开源文件、编辑 href、删除链接）；未实例化的模板链接与普通 rcss 链接一样是 `#head-link` 节点。
- 所有链接编辑都是**文本级命令**：全程可撤销，保存时 head 区域字节级原样保留。

编辑器顶部（Inspector 的 Nested Documents / head 区）可添加链接。样式表本身的编辑用 TextEditor tab 打开 `.rcss` 文本编辑，保存后画布自动刷新（见第 9 节）。

## 8. 复制 / 剪切 / 粘贴 / 撤销

- **Ctrl+C / Ctrl+X / Ctrl+V**：真系统剪贴板——存的是独立 RML 片段，可跨文档、跨编辑器粘贴；粘贴时 id 冲突自动加 `-2`/`-3` 后缀。
- **Ctrl+D**：原地复制（duplicate）。
- **Delete**：删除（多选时批量，一步 undo）。
- **Ctrl+Z / Ctrl+Y**：全链撤销/重做；多选批量操作整体是一步。
- **Alt+↑ / Alt+↓**：流内上移/下移（与兄弟交换位置）。
- 快捷键属于画布窗口：输入焦点在文本框时不会误触发。

## 9. 预览、运行与热刷新

- **Play/Stop（工具栏）**：把当前编辑的场景 + 本文档在 Game View 中真实运行（先自动保存；外部改动未决时中止）。运行会话独占输入；停止后焦点回到编辑 tab。运行中的 GameView **不会**因文件改动自动刷新。
- **热刷新（编辑画布）**：`.rcss` / `.rml` 文件在磁盘上被外部工具（含编辑器自己的 TextEditor tab）保存后，**编辑画布自动更新**：
  - 引用的样式表/模板变了 → 画布按新样式重投影，模型不动、无 undo、无 dirty。
  - 当前文档本身变了且无未保存编辑 → 画布就地重载。
  - 有未保存编辑时不自动重载（外部改动交给保存守卫裁决），拖拽手势进行中会延后到松手后。

## 10. 保存行为

- Ctrl+S / 工具栏 Save 保存。保存是**最小差异**的：只重写真正改动的片段，你的缩进、注释、未编辑区域原样保留；数据绑定标记（`{{...}}`）、模板、未识别的标准构造一律原样透传，不重写、不丢失。
- **覆写守卫**：若文件在打开期间被外部修改，保存会弹出确认对话框（Overwrite / Cancel），绝不静默覆盖他人改动。
- 输出是标准 RML——RmlUi 引擎、其他工具、人手写文件三者无缝互认。

## 11. 快捷键速查

| 按键 | 作用 |
|---|---|
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴（系统剪贴板） |
| `Ctrl+D` | 原地复制 |
| `Delete` | 删除选中 |
| `Alt+↑` / `Alt+↓` | 流内上移 / 下移 |
| `F` | 视图适配（Fit） |
| `Esc` | 清除选择；拖拽/框选/平移中取消当前手势 |
| 鼠标中键拖动 | 平移 |
| 滚轮 | 缩放（指针锚定） |
| 双击 | 编辑文字 / 打开嵌套文档 |

## 12. 技巧与已知行为

- 新文档记得在 head 链接一份 rcss（例如 `../CoreData/UI/rml.rcss`），否则原生控件没有外观。
- 图片路径用 `/` 起始的 Data 相对路径或精灵名。
- `z-index`、`top/left` 等定位属性只在元素已定位时生效——面板恒定可见并带 tooltip 提示，不会因"当前不生效"而隐藏。
- `order` / `row-reverse` 等改变视觉序的属性刻意不进结构化面板（视觉序背离文档序），走 Inline Style raw。
- 画布缩放百分比旁的 Canvas 下拉可切换预览分辨率（预设 1024x768 / 1280x720 / 1920x1080 / 768x1024 或自定义 W/H），画布尺寸是编辑器全局视图偏好，不会写进 `.rml`。
