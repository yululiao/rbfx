## 提交前必做（3 件事）

### 1. 补拍并插入游戏截图（说明书）

说明书中所有红色【此处插入截图：…】占位（共 10 处）必须替换为真实游戏截图，
否则审查会以「文档与软件不符」补正。建议截图来源：

- 抖音开发者工具模拟器（竖屏 393x852 或相近机型），或
- Windows 版直接运行游戏窗口截图

截图清单：开局画面、摇杆走位、自动开火战斗、升级提示、大船炮击预警、
宠物狗作战、登船按钮、驾船出海、主界面全貌、结算面板。
插入后把占位文字删除，并在图下保留一行图注（如「图 1 游戏开局画面」）。

### 2. 填写封面与日期

- 说明书封面「著作权人」「日期」两处下划线补全（著作权人 = 身份证姓名）。
- 填报信息参考中的「开发完成日期」：填代码定稿日（须早于申请日）。

### 3. 导出 PDF

源程序与说明书分别用 Word/WPS「另存为 PDF」后上传（登记系统只收 PDF）。
导出后快速抽查：页眉名称版本是否正确、页码是否连续、源程序是否恰好 60 页。

## 官网提交步骤（全程线上，官费 0 元）

1. 打开中国版权保护中心官网 www.ccopyright.com.cn，注册账号并完成**个人实名认证**
   （身份证正反面 + 手持身份证照片，审核约 1–3 个工作日）。
2. 进入「计算机软件著作权登记（R11）」→ 立即登记 → 我是申请人（个人）。
3. 按 `03_申请表填报信息参考.md` 逐项填报并电子签章。
4. 上传两份 PDF 鉴别材料，提交。
5. 受理约 5–7 天，审查约 45–55 天，一次性通过总周期约 50–60 天；
   收到补正通知须限期修改重交（周期重新计算）。
6. 通过后在线下载**电子登记证书**（与纸质证书同等法律效力，抖音平台认可）。

## 一致性自查（每次提交前过一遍）

- 申请表软件全称 = 两份材料页眉名称 = 消灭海盗游戏软件；版本号均为 V1.0
- 著作权人姓名 = 账号实名认证姓名
- 说明书截图中的游戏与名称描述一致
- 开发完成日期 ≤ 首次发表日期（建议选「未发表」）
- 后续抖音上架的游戏名称保持「消灭海盗」，不要改名

## 代码变动后重新生成

```powershell
py "d:\openSrc\rbfx\rbfxProjs\FireGame\软著\gen_docs.py"
```

会自动重排源程序 60 页、重算代码行数并更新填报信息参考。
注意：说明书 docx 会被覆盖，已插入的截图会丢失——**先截图再重新生成，或重新生成后重新插图**。

## 时间线建议

- 本周：完成实名认证 + 补拍截图 + 导出 PDF + 提交申请
- 约 50–60 天后：拿到电子证书
- 拿证后：走抖音小游戏的资质上传 → 作品备案（无版号 IAA 通道）→ 提审上架
