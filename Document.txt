
1.游戏内lua代码补全和提示
c++导出的类型,靠rbfx\rbfxProjs\EmptyTest\_apidocs下的*.d.lua(rbfx/gen_editor_lua_api.bat &gen_engine_lua_api.bat 生成)
bat会调用Source/Tools/ApiDocGen/generate_api_docs.py去解析c++ lua_binding代码，导出c++ bind 到lua的类型输出到rbfx\rbfxProjs\EmptyTest\_apidocs
你自己写的游戏逻辑Lua,LuaLS 会直接分析工作区里的 .lua 源码。自动实现代码提示。但只需满足三件事:
两个文件在同一工作区目录树内(你现在开 EmptyTest,Data/Scripts/** 全在里面)——这点已满足。
require 能解析到那个文件(见下命名规则)。
模块要"导出类型"——这是最关键、也最容易被忽略的一步。

游戏逻辑lua范式：按范式写，会自动有语法提示(VsCode Lua插件(sumneko)支持)
-- Data/Scripts/ui/kit.lua
---@class UiKit
local M = {}

---@param node Node          -- 直接引用引擎类型,因为 engine.d.lua 在 workspace.library 里
---@param w integer
---@param h integer
function M.centerOn(node, w, h) ... end

---@return Timer             -- 返回值类型也会传播
function M.makeTimer(...) ... end

return M
